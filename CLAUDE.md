# Claude Skills Testing

This project is a Claude plugin used for testing Claude skills.

## Installation

```bash
claude plugin marketplace add https://github.com/SubframeApp/claude-skills-testing
claude plugin install claude-skills-testing@claude-skills-testing
```

## Skills

- `/get_best_dog` - Returns the best dog breed
- `/get_best_steaks` - Returns the best steaks
- `/get_best_color` - Returns the best color
- `/get_best_dj` - Returns the best DJ
